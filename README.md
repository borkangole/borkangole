## 🏗️ Featured Projects

### 🗺️ LGU-SDSS — Spatial Decision Support System *(Thesis · Completed)*
> A GIS platform for Philippine LGUs: upload barangay boundaries, hazard maps and CBMS data, then see **which barangays and households need help first** — and what kind. Social vulnerability, barangay capacity and flood/landslide exposure are mapped side by side, down to each household, with family network analysis and an "Ask the Data" query page. Built on real data for the Municipality of San Miguel, Iloilo — **7,253 households across 24 barangays**.

`React.js` `Flask` `Python` `PostgreSQL` `PostGIS` `Leaflet.js` `NetworkX` `Node.js`

---

### 🪸 Coral Vision *(Research · Mobile App · In Development, 90%)*
> A mobile app that identifies coral species from a single photo — **fully on-device, no signal needed** — then returns each species' conservation profile and geo-tags every find on a map for reef monitoring in Capiz. Classification runs on a fine-tuned EfficientNet-B0 model exported to TensorFlow Lite.

`React Native` `Expo` `TensorFlow Lite` `Keras` `Python` `scikit-learn`

---

### 🏢 TPPG Portal *(Mockup · Deploying Soon)* — [Live Portal](https://tppg-portal-updated-production.up.railway.app/)
> A role-based real estate management system for The Premier Property Group — agent hierarchy, property listings, buyer records, and automated commission computation. Built collaboratively as a full-stack developer.

`Node.js` `Express.js` `Supabase` `PostgreSQL`

---

### 🏘️ TPPG Public Website *(Prototype · Deploying Soon)* — [Live Prototype](https://thepremierpropertygroup.vercel.app/)
> The buyer-facing website for The Premier Property Group — property search, a map-based listings explorer, a four-question property matcher, and inquiry forms that route leads to agents.

`Next.js` `TypeScript` `Tailwind CSS` `Supabase` `Leaflet`
